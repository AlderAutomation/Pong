# Pong

Classic style Pong made with C and Raylib. Made this to expand my C and game dev knowledge and because I have a University course that is using C and I have no C experience prior.  

# How to Play  

Easiest way to play is to head over to my [Ithio](https://matthewalderautomation.itch.io/pong) page and play it in the web browser.  

# What I learned 

SO MUCH. I learned about C basics, Raylib, compisition programming, CMake, building and releasing, and getting and acting on player feedback.
